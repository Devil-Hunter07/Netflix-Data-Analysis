# 🎬 Netflix Content Strategy & Trends Analysis

## 📌 Project Overview
This project is submitted as the final capstone for the **AICTE | IBM SkillsBuild Data Analytics with AI Internship 2026 | BharatCares**. It analyzes a dataset of Netflix Movies and TV Shows to discover business trends in content types, global production countries, and platform growth over time.

## 🔗 Dataset Link
[Netflix Movies and TV Shows - Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)

## 🛠️ Technologies & Libraries Used
- **Language**: Python
- **Libraries**: Pandas, Matplotlib, Seaborn, Kagglehub
- **Environment**: Jupyter Notebook (VS Code)

## 🚀 Setup & Run Instructions
1. Download the dataset using `kagglehub` or from the Kaggle link provided above.
2. Ensure the `netflix_titles.csv` file is accessible in the project directory.
3. Install the required libraries using the `requirements.txt` file by running:
   `pip install -r requirements.txt`
4. Open `Himesh_NetflixAnalysis.ipynb` in Jupyter Notebook.
5. Run all the cells sequentially to load the data, clean missing values, and view the visual insights.

## 📊 Key Insights Derived
- **Movies > TV Shows**: Feature films significantly outnumber TV shows on the platform.
- **Top Markets**: The United States and India are the leading content-producing countries for Netflix.v
